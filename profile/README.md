## Proyectos destacados

### 🚗 [Gesture Sheep Cart](https://github.com/AxelC2code/gesture-sheep-Cart)

Vehículo robótico controlado mediante gestos de la mano. Dos ESP8266 se
comunican con **ESP-NOW** para lograr baja latencia; un MPU6050 detecta la
inclinación y una pantalla OLED proporciona retroalimentación. Incluye un
sistema failsafe para detener los motores si se pierde la comunicación.

### 📦 [Ark System](https://github.com/AxelC2code/ark-system)

Aplicación de escritorio para gestión de inventarios desarrollada con **C# y
Windows Forms**. Incluye validación de datos, búsqueda, ordenamiento por
Insertion Sort, estructuras `List` y `Dictionary`, recursividad y manejo de
excepciones.

### 📅 [Kranklin Labs](https://github.com/AxelC2code/Kranklin-Labs)

Sistema académico construido con **Google Apps Script y Google Sheets** para
organizar cursos, horarios, actividades, asistencia, revisiones y seguimiento
semanal con distintos roles de usuario.
